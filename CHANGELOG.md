# Changelog

All notable changes to this project. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). The version
number itself is kept in `VERSION`.

## [Unreleased]

## [1.0.0] - 2026-09-25

First stable release. The interface documented in `doc/REFERENCE.md` (the
`.csvy` format, `inp2gp.py`'s command line and outputs, the template contract,
`\gnuplotfit`, the Gantt template, and the Makefile targets) now follows
semantic versioning: breaking changes to it need a new major version.

### Added
- Docs website on GitHub Pages, built with pandoc and make (`make site`) and
  published by `.github/workflows/docs.yml`. It uses github-markdown-css, has
  a nav bar and footer, and shows the version from `VERSION`. The workflow
  also checks internal links and anchors.
- The top-level README is published on the site as `ABOUT.html`. Links
  between the README and the docs point to site pages; other files point to
  GitHub.
- `make overleaf`: collects what a LaTeX project without gnuplot (such as
  Overleaf) needs into `overleaf/`: gnuplot's TikZ style files, generated by
  the local gnuplot, plus `gnuplotfit.sty` and the figures.
- README: *Using it in your own paper* (three setups), and the versions the
  project is tested with.

### Changed
- The example document `test-v6.tex` is now `example.tex` (the default
  `DOC`).
- The version is kept in `VERSION` (and the `.sty` headers) only; the README
  and reference no longer repeat it.

### Fixed
- `make -C doc site` no longer re-renders the tutorial images, which on a
  fresh checkout needed gnuplot and LaTeX.

## [0.0.8] - 2026-09-25

### Changed
- Documentation split into `doc/REFERENCE.md` (the complete rules, moved out
  of the README, plus a new Makefiles section) and `doc/tutorials/`. The
  README is cut to an overview, with links to both at the top.
- `test/test_v6.py` renamed to `test/test_inp2gp.py`.

## [0.0.7] - 2026-09-25

### Changed
- **Breaking:** new frontmatter protocol. The header has `template`, `vars`
  and `gnuplot` keys, as a mapping or a list of one-key mappings.
  - `template: path/to/STEM` names `STEM.gp` (the plot) and `STEM.csvy` (its
    defaults, a header with no data). `--template=STEM` on the command line
    overrides it.
  - `vars` become gnuplot variables, merged over the template's defaults.
    Unknown vars are an error, unless the template tests them with
    `exists()`.
  - `gnuplot` entries become `set k v` lines (`true`/empty: `set k`;
    `false`: `unset k`), run before the template. `terminal`, `output`,
    `datafile` and `table` are reserved.
- `templates/gantt.gp` keeps only the vars it computes with. Labels and
  styling moved to `templates/gantt.csvy`, where they can be overridden.

### Added
- A y-axis label example (`ylabel` with gnuplot's `offset`) in the advanced
  tutorial.

### Fixed
- make no longer tries to build a template's `STEM.gp` from its `STEM.csvy`:
  `NAME.d` marks both as sources.

## [0.0.6] - 2026-09-25

### Added
- First version. `NAME.csvy` (YAML frontmatter and CSV data) is turned by
  `inp2gp.py` into `NAME.gp`, `NAME.dat` and `NAME.d`, and gnuplot's `tikz`
  terminal renders `NAME.gp.tex`.
- `gnuplotfit.sty`: `\gnuplotfit[<width>][<height>]{<file>}` stretches a
  figure to a given size while its text keeps the document's size.
- `templates/gantt.gp`: a Gantt chart with a buffer bar after each task.
- Makefile targets `figs`, `pdf`, `check`, `watch`, `docs`, `test`, `clean`
  and `distclean`. Figures are committed, and rebuilds are repeatable.
- Regression tests with golden outputs, and tutorials with rendered images.
